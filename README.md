# DNA-Sequence-Analyzer / version 1.0
Python tool for basic DNA analysis.

##Features

- Sequence length
- Base count
- Per-base composition (%)
- GC content
- Motif search
- Motif position
- Recese complement sequence
- Sequence validation

##Planned future updates

- GC content by region
- Codon analysis

##Future projects

- DNA-to-Protein Translation tool
